DESCRIPTION
Votre mobile est éteint? Vous êtes trop occupé pour répondre au téléphone ou vous êtes déjà en communication? Où que vous soyez, Djezzy vous offre la possibilité de basculer vos appels vers votre messagerie vocale. Ainsi, vous ne manquerez plus les messages importants laissés par vos correspondants.
COMMENT ÇA MARCHE ?
Pour y accéder, rien de plus simple : Il suffit d’appeler le 555 et de vous laisser guider. Aussi, il vous est possible de personnaliser votre boîte vocale ainsi que le message d’accueil. Votre boîte vocale n’en sera que plus conviviale et personnalisée.
Comment activer le renvoi vers votre boîte vocale?
Il suffit de faire un renvoi d’appels gratuitement vers le 550 selon le type de renvoi désiré (occupé, injoignable, inconditionnel, non réponse), selon les commandes abrégées des différents Renvois d’Appel sur la section Renvoi d’appel, et en remplaçant sur la commande « le numéro souhaité » par « 550 ».
Comment consulter vos messages vocaux ?
Pour consulter vos messages, il suffit d’appeler le 555 depuis votre mobile.
Vous pouvez également consulter votre boîte vocale à distance depuis un autre Opérateur en appelant le 0770 850 555 ou le +213 770 850 555 depuis l’étranger.
Lorsque vous recevez un message vocal, une notification par SMS vous sera envoyée.
Comment désactiver ma boîte vocale ?
En utilisant les codes d’annulation des renvois, à composer directement sur le clavier, le code est : ” # # code du renvoi # ” puis valider.
En composant le code ##002# pour annuler tous les renvois.
TARIFICATION
La Messagerie Vocale vous est offerte, sans frais d’activation ni abonnement mensuel, et ce, pour tous les abonnés Djezzy. La consultation de vos messages à partir de votre mobile Djezzy (accès direct) est gratuite pour tous les abonnés Djezzy, facturée à 10Da /Appel pour abonnés ALLO.
La consultation de vos messages à distance (Local et Roaming) est facturée aux tarifs en vigueur.
