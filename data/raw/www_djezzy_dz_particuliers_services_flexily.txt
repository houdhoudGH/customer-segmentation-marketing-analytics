DESCRIPTION
Avec le service Flexily, les abonnés Djezzy prépayés et control ont la possibilité de recevoir et transférer  du crédit à leurs proches et amis.
Le montant du crédit à transférer est compris entre 50 à 100 Da.
Le nombre de transferts par jour est limité à 6 transactions.
LE CODE PIN DE RECHARGEMENT
Afin de sécuriser l’opération de transfert de crédit, Djezzy a mis en place un code PIN de rechargement composé de 00000 par défaut pour tous ses abonnés Djezzy prépayés et Control.
Si vous souhaitez changer votre code PIN de transfère de crédit Flexily , composez le * 780 * Ancien code PIN (00000)*Nouveau code PIN (composé de 4 numéros exemple (1234)* confirmation du nouveau code PIN# puis appuyer sur la touche « Appel », la formule est gratuite.
COMMENT ÇA MARCHE?
Pour transférer une partie de votre crédit à un proche ou à un ami, il vous suffit de :
Composer le *770*numéro du correspondant prépayé * Le montant à transférer (entre 50 Da minimum est 100 Da maximum) * le code PIN de rechargement # Puis appuyer sur la touche «Appel».
Une fois la formule envoyée, vous recevrez un SMS de validation:
Si vous répondez à cet SMS en tapant 1, vous recevrez un deuxième SMS de confirmation de l’envoi du crédit.
Et si vous répondez en tapant 2, la demande de transfert sera alors annulée.
Aussi vous pouvez vous connectez à l’application Djezzy internet (Androïd | iOS) sur la fenêtre des transferts de crédit et insérez le numéro du correspondant prépayé, le montant à transféré et votre code PIN.
Vérifiez vos montants mensuels transférés et le montant restant en utilisant la formule gratuite *775#.
TARIFICATION
L’abonné sera facturé 10 Da pour chaque transfert effectué entre 50 à 100 Da.
