DESCRIPTION
Flexy de Djezzy est un service destiné à tous les abonnés Djezzy. Il vous permet de recharger le montant que vous voulez au numéro que vous souhaitez (confirmation par SMS) ainsi que de payer votre facture sans déplacement !
Il est disponible dans tous les points de vente Djezzy.
FLEXY CODE
Cette fonctionnalité permet de communiquer un code de substitution à 8 chiffres à la place de votre numéro de téléphone au moment d’effectuer votre recharge.
L’attribution du Flexy Code se fait via *765# (max cinq transactions par jour et par utilisateur). Ci-dessous les formules à suivre :
Rechargement Paiement de facture
Numéro d’appel / Flexy Code *760*numéro d’appel*la somme*PIN# *761*numéro d’appel*la somme*PIN#
